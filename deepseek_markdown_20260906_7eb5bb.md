# GHZ Multi Downloader

Multi-platform media downloader for YouTube, TikTok, Facebook, and Instagram.

## Features

- ✅ Download videos from YouTube, TikTok, Facebook, Instagram
- ✅ Support MP4, MP3, JPG formats
- ✅ Auto-detect platform from URL
- ✅ Quality selection for videos
- ✅ Beautiful responsive UI
- ✅ Rate limiting protection
- ✅ Caching for better performance

## Tech Stack

- Cloudflare Workers
- RapidAPI
- HTML/CSS/JavaScript
